# Artemis iOS (protótipo de interface)

Código-fonte inicial em SwiftUI. **Ainda não é um aplicativo compilado ou instalável**.

Para testar, crie um projeto iOS App em Xcode com SwiftUI, substitua os arquivos gerados por `ArtemisApp.swift` e `ContentView.swift` e compile em um Mac compatível. O repositório ainda não contém um projeto `.xcodeproj` nem integração com llama.cpp.

Próximas etapas: projeto Xcode reproduzível, motor de inferência local, gerenciamento de modelo, STT/TTS offline, protocolo de comandos autenticado e testes em hardware real.

O chat atual é uma interface demonstrativa: não envia comandos ao ESP32 nem opera o alarme.
